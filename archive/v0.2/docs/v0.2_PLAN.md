# Implementation Plan: Enhanced Kanji Flashcard Study Mode
**Version:** v0.2.0
**Created:** 2026-01-20
**Status:** Awaiting Approval

---

## Overview

Transform the kanji flashcard system from a simple click-to-expand grid into a comprehensive study tool with enhanced card information and dedicated study mode interface.

### Phases
- **Phase 1:** Enhanced Card Content (richer information)
- **Phase 2:** Study Mode Interface (dedicated review experience)

---

## Phase 1: Enhanced Card Content

### Current Card Structure
```html
<div class="kanji-card" onclick="toggleKanji(this)">
  <div class="kanji-character">食</div>
  <div class="kanji-details">
    <div class="kanji-reading">On: ショク / Kun: た(べる)</div>
    <div class="kanji-meaning">Meaning: eat, food</div>
  </div>
</div>
```

### Enhanced Card Structure

### New Data Attributes
- `data-jlpt="N5|N4|N3|N2|N1"` - For filtering
- `data-kanji="食"` - For study mode selection
- `data-marked="true|false"` - For "mark for review" feature (stored in localStorage)

```javascript
function nextCard() {
  if (studyState.currentIndex < studyState.cards.length - 1) {
    showCard(studyState.currentIndex + 1);
  } else {
    // End of deck, show results
    showResults();
  }
}

/**
 * Navigate to previous card
 */
function previousCard() {
  if (studyState.currentIndex > 0) {
    showCard(studyState.currentIndex - 1);
  }
}

/**
 * Toggle "mark for review" on current card
 * Uses localStorage to persist marks
 */
function toggleMark() {
  const card = studyState.cards[studyState.currentIndex];
  const kanji = card.character;

  // Get current marks from localStorage
  let markedKanji = JSON.parse(localStorage.getItem('markedKanji') || '[]');

  if (markedKanji.includes(kanji)) {
    // Remove mark
    markedKanji = markedKanji.filter(k => k !== kanji);
    updateMarkButton(false);
  } else {
    // Add mark
    markedKanji.push(kanji);
    updateMarkButton(true);
  }

  // Save to localStorage
  localStorage.setItem('markedKanji', JSON.stringify(markedKanji));
}

/**
 * Update mark button appearance
 */
function updateMarkButton(isMarked) {
  const markBtn = document.getElementById('mark-btn');
  const markIcon = markBtn.querySelector('.mark-icon');

  if (isMarked) {
    markIcon.textContent = '⭐';
    markBtn.classList.add('marked');
  } else {
    markIcon.textContent = '☆';
    markBtn.classList.remove('marked');
  }
}

/**
 * Check if a kanji is marked for review
 */
function isKanjiMarked(kanji) {
  const markedKanji = JSON.parse(localStorage.getItem('markedKanji') || '[]');
  return markedKanji.includes(kanji);
}

/**
 * End study session early
 */
function endStudy() {
  if (confirm('End study session? Your progress will not be saved.')) {
    showResults();
  }
}

/**
 * Show results screen
 */
function showResults() {
  document.getElementById('study-active-screen').style.display = 'none';
  document.getElementById('study-results-screen').style.display = 'block';

  // Update statistics
  const cardsReviewed = studyState.currentIndex + 1;
  const cardsMarked = studyState.cards.filter(c => isKanjiMarked(c.character)).length;

  document.getElementById('cards-reviewed').textContent = cardsReviewed;
  document.getElementById('cards-marked').textContent = cardsMarked;
}

/**

function restartStudy() {
  showCard(0);

  document.getElementById('study-active-screen').style.display = 'block';
}

function returnToStart() {
```

## Answer to "Mark for Review" Question

**Can we implement "mark for review" now without a profile feature?**

**YES!** We can use **localStorage** - a browser-based storage mechanism that:

✅ **Pros:**
- No backend/database required
- Persists across browser sessions on the same device
- Simple JavaScript API: `localStorage.setItem()` and `localStorage.getItem()`
- Perfect for single-user learning tools
- Can store marked kanji as a JSON array: `["食", "日", "本"]`

❌ **Cons:**
- Device-specific (marks won't sync across devices)
- User clears browser data = marks are lost
- Limited to ~5-10MB storage (more than enough for kanji marks)

**Implementation:**
```javascript
// Mark a kanji
let markedKanji = JSON.parse(localStorage.getItem('markedKanji') || '[]');
markedKanji.push('食');
localStorage.setItem('markedKanji', JSON.stringify(markedKanji));

// Check if marked
const isMarked = markedKanji.includes('食');

// Unmark
markedKanji = markedKanji.filter(k => k !== '食');
localStorage.setItem('markedKanji', JSON.stringify(markedKanji));
```

This is the same approach used by many web-based learning tools before implementing user accounts. It's perfect for your current needs!
