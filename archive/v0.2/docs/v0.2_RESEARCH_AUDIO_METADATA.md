## 1. Audio Options Research

### Current Implementation
- Uses browser's **Web Speech API** (text-to-speech)
- Function: `speak(text)` in `js/shared.js`
- **Pros:** No cost, works offline, no API key needed
- **Cons:** Robot-like quality, inconsistent across browsers

### Better Audio Options for 2026

#### Option A: Continue with Web Speech API (Free)
**Recommendation: START HERE**
- Already implemented
- Zero additional cost
- Works immediately
- Quality has improved in modern browsers
- Japanese support is decent in Chrome/Edge

**Action:** Keep current implementation, but optimize:
```javascript
// Enhanced Japanese speech synthesis
function speakJapanese(text) {
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = 'ja-JP';
  utterance.rate = 0.8; // Slower for learning
  utterance.pitch = 1.0;

  // Try to select a Japanese voice if available
  const voices = window.speechSynthesis.getVoices();
  const japaneseVoice = voices.find(voice => voice.lang === 'ja-JP');
  if (japaneseVoice) {
    utterance.voice = japaneseVoice;
  }

  window.speechSynthesis.speak(utterance);
}
```

#### Option B: Google Cloud Text-to-Speech API (Paid, Natural Quality)
**Cost:** $4 per 1 million characters
**Quality:** Neural voices, very natural sounding
**Implementation:** Requires API key, backend server to hide key
**Verdict:** Overkill for current needs, revisit if scaling

#### Option C: Hybrid Approach - Pre-recorded Common Kanji (Future)
**Concept:**
- Record/download audio for ~500 most common kanji
- Store as MP3 files in `/audio/kanji/` folder
- Fall back to Web Speech API for uncommon kanji
**Pros:** Best quality for common kanji
**Cons:** Time-intensive, storage requirements
**Verdict:** Good future enhancement, not for v0.2

### Recommendation
**Use optimized Web Speech API for v0.2**
- Zero cost, works now
- Quality is acceptable for learning
- Can upgrade to pre-recorded audio later as enhancement

## 2. JLPT Level Assignment Research

### Key Findings

#### No Official JLPT Kanji Lists
- **JLPT administrators state:** No official kanji lists exist
- However, in practice, kanji patterns by level are well-established
- Community resources (Kanshudo, JLPTsensei, etc.) provide reliable estimates

#### Estimated Kanji Counts by Level
| Level | Kanji Count | Description |
|-------|-------------|-------------|
| **N5** | ~80-100 | Basic kanji for everyday use |
| **N4** | ~170-300 | Practical kanji for daily situations |
| **N3** | ~370-660 | Intermediate reading comprehension |
| **N2** | ~380-1140 | Advanced kanji for newspapers/novels |
| **N1** | ~2136 | Joyo kanji (official education kanji) |

**Note:** Numbers are cumulative - N4 builds on N5, etc.

#### Can Kanji Appear in Multiple Levels?
**Answer: YES, conceptually**

While a kanji is typically "introduced" at one JLPT level, the **usage contexts** and **vocabulary compounds** can span multiple levels:

**Example: 食 (eat)**
- **N5:** 食べる (taberu - to eat) - basic verb
- **N4:** 食事 (shokuji - meal) - common compound
- **N3:** 外食 (gaishoku - dining out) - more advanced
- **N2:** 食糧 (shokuryou - provisions/food supply) - formal/news

**Implication for Our System:**
We should tag kanji with:
1. **Primary JLPT Level:** Where the kanji is typically introduced (N5, N4, etc.)
2. **Vocabulary Level Range:** The range of contexts it appears in

### Recommended Tagging Approach

#### Single Primary Level
```javascript
jlpt: "N5"  // Where kanji is typically introduced
```

#### With Vocabulary Level Range (Future Enhancement)
```javascript
jlptPrimary: "N5",
jlptVocabRange: ["N5", "N4", "N3"]  // Vocabulary using this kanji spans these levels
```

**For v0.2: Use single primary level**
- Simpler to implement
- Easier to filter
- Can add range later if needed

### JLPT Level Assignment Process

For each kanji, I will:
1. Cross-reference multiple sources (Kanshudo, JLPTsensei, WaniKani level maps)
2. Assign the most commonly agreed-upon level
3. For ambiguous cases, assign the **lower (easier) level** to be conservative

**Example Sources to Use:**
- [Kanshudo JLPT Kanji Collections](https://www.kanshudo.com/collections/jlpt_kanji)
- [JLPTsensei Kanji Lists](https://jlptsensei.com/jlpt-n5-kanji-list/)
- Community consensus from WaniKani level mappings

## 3. Metadata Structure for Kanji

### Core Metadata Design

Each kanji should have the following metadata structure:

```javascript
{
  // Core Identity
  character: "食",

  // Readings
  readings: {
    on: ["ショク", "ジキ"],      // Can have multiple on'yomi
    kun: ["た(べる)", "く(う)"]   // Can have multiple kun'yomi
  },

  // Meaning
  meanings: ["eat", "food", "meal"],  // Multiple English meanings

  // JLPT Level
  jlpt: "N5",  // Primary JLPT level

  // Topic Tags (NEW - for filtering by theme)
  topics: ["home-life", "restaurant"],  // Which topic sections this appears in

  // Semantic Categories (NEW - for filtering by meaning)
  categories: ["food", "daily-actions"],  // Thematic groupings

  // Part of Speech Context (NEW)
  usageTypes: ["verb", "noun"],  // How this kanji is commonly used

  // Frequency (OPTIONAL)
  frequency: "common",  // common | uncommon | rare

  // JLPT Grade (OPTIONAL - for finer sorting)
  grade: 4,  // Joyo kanji grade (1-6 for elementary, 8 for secondary)

  // Example Words
  words: [
    {
      japanese: "食べる",
      hiragana: "たべる",
      english: "to eat",
      jlpt: "N5"
    },
    {
      japanese: "食事",
      hiragana: "しょくじ",
      english: "meal",
      jlpt: "N4"
    },
    {
      japanese: "食堂",
      hiragana: "しょくどう",
      english: "cafeteria, dining hall",
      jlpt: "N4"
    }
  ],

  // Example Sentence
  sentence: {
    japanese: "朝ごはんを食べます。",
    hiragana: "あさごはんをたべます。",
    romaji: "Asa-gohan wo tabemasu.",
    english: "I eat breakfast."
  },

  // Study Metadata
  strokeCount: 9,  // OPTIONAL - for stroke order practice
  radicals: ["人", "艮"],  // OPTIONAL - component radicals

  // Similar/Related Kanji (OPTIONAL - future enhancement)
  similar: ["飯", "飲"],  // Lookalike or related kanji

  // Mnemonics (OPTIONAL - future enhancement)
  mnemonic: "Person (人) standing next to good (艮) food"
}
```

## 4. Recommended Filters for Study Mode

Based on research of leading Japanese learning apps (Anki, WaniKani, Takoboto, Drops), here are recommended filters:

### Phase 1 Filters (v0.2 - Implement Now)

#### 1. **JLPT Level Filter** ✅
- All Levels
- N5 only
- N4 only
- N3 only
- N4 & N5 combined
- etc.

**UI:** Button group, single or multi-select

#### 2. **Topic Filter** ✅
- All Topics
- Home Life
- Shopping
- Restaurant
- Travel
- (Future: combined study mode across all topics)

**UI:** Dropdown or button group

#### 3. **Category Filter** ✅
- All Categories
- Food & Eating
- Family Members
- Time & Morning
- House & Rooms
- Daily Activities
- Clothing
- Numbers & Counting
- etc.

**UI:** Dropdown or tag-based multi-select

#### 4. **Marked for Review** ✅
- All cards
- Marked only
- Unmarked only

**UI:** Checkbox toggle

### Phase 2 Filters (Future Enhancements)

#### 5. **Part of Speech / Usage Type**
- Nouns (名詞)
- Verbs (動詞)
- Adjectives (形容詞)
- Counters (助数詞)

**Why useful:** Some learners struggle more with verbs than nouns, etc.

#### 6. **Frequency**
- Common kanji (top 500)
- Uncommon kanji
- Rare kanji

**Why useful:** Prioritize high-frequency kanji for practical communication

#### 7. **Mastery Status** (Requires SRS)
- New cards (never studied)
- Learning (currently reviewing)
- Mastered (confident)
- Struggling (marked + low self-assessment)

**Why useful:** Focus on problem areas

#### 8. **Stroke Count Range**
- Simple (1-5 strokes)
- Moderate (6-10 strokes)
- Complex (11+ strokes)

**Why useful:** Build from simple to complex
