Workflow Hub Help

What is this?

The Workflow Hub is your central command center for dbt-playground. It answers: "Where was I, and what should I do next?"

How to Use

  • Automatic: Run uv run scripts/playground-server.py and data loads automatically
  • Manual: Paste temp/WORKFLOW_STATE.md to see active tracks
  • Paste temp/SESSION_SUMMARY_*.md for quick resume context
  • Paste git worktree list output to see parallel work
  • Click "Copy Context" to get resume text for Claude

Understanding the Display

  • Quick Resume - Key context for continuing work
  • Active Tracks - Features in progress with phase status
  • Agent Activity - Recent completions from the assembly line
  • Worktrees - Parallel development sessions
  • Playgrounds - Links to other visual tools

Keyboard Shortcuts

  • R - Refresh / re-parse all data
  • 1 - Switch to WORKFLOW_STATE tab
  • 2 - Switch to SESSION_SUMMARY tab
  • 3 - Switch to git worktree tab
  • ? - Show this help
  • Esc - Close modals

Data Sources

  • temp/WORKFLOW_STATE.md - Track status, metrics
  • temp/SESSION_SUMMARY_*.md - Session checkpoint
  • temp/AGENT_REPORTS/ - Per-feature agent artifacts
  • git worktree list - Parallel development

Related Tools

  • Worktree Coordinator - Full worktree management
  • Agent Visualizer - Workflow diagrams (planned)
  • Mermaid Designer - Create architecture diagrams
