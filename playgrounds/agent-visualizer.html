Agent Visualizer Help

Overview

The Agent Visualizer displays workflow state from temp/WORKFLOW_STATE.md, showing phase progression, execution timeline, and track details.

Loading Data

  • Paste: Click "Load" and paste the contents of WORKFLOW_STATE.md
  • Drag & Drop: Drag the file onto this page
  • Cached: Data is saved to localStorage for quick reload

Tabs

  • Workflow Diagram: Mermaid flowchart showing phase progression
  • Timeline: Execution sequence with elapsed time per phase
  • State Inspector: YAML frontmatter and track details

Phase Colors

  • Green = Complete
  • Blue = In Progress
  • Gray = Pending
  • Red = Failed/Blocked
