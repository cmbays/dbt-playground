# Version 0.1 - Topics Folder Migration Plan

## Summary

Reorganize content into `topics/` subdirectory to eliminate ambiguity and follow web development best practices. Rename `home/` to `home-life/` to avoid confusion with homepage.

**Version**: v0.1.0
**Type**: MAJOR architectural change
**Risk Level**: Medium (many file moves and link updates)
**Estimated Impact**: ~25 HTML files, all navigation links, documentation updates

---

## Current Structure (Before)

```
japanese/
├── index.html
├── home/              # ← AMBIGUOUS (looks like homepage folder)
│   ├── phrases.html
│   ├── dialogue.html
│   └── ... (10 files)
├── shopping/
│   └── ... (7 files)
├── restaurant/
│   └── ... (1 file)
├── travel/
│   └── ... (7 files)
├── css/
│   └── shared.css
├── js/
│   └── shared.js
└── docs/
```

**Problems**:
1. `/home/` looks like site's homepage, but it's a content topic
2. Root directory cluttered with content folders
3. Doesn't scale well (10+ topics = root clutter)
4. Unclear separation between content and infrastructure

---

## New Structure (After)

```
japanese/
├── index.html         # Entry point (unchanged location)
├── topics/            # ← NEW: All content here
│   ├── home-life/    # ← RENAMED from "home"
│   │   ├── phrases.html
│   │   ├── dialogue.html
│   │   └── ... (10 files)
│   ├── shopping/
│   │   └── ... (7 files)
│   ├── restaurant/
│   │   └── ... (1 file)
│   └── travel/
│       └── ... (7 files)
├── css/
│   └── shared.css     # Location unchanged
├── js/
│   └── shared.js      # Location unchanged
└── docs/
```

**Benefits**:
1. ✅ Clear separation: content vs. infrastructure
2. ✅ No ambiguity: "home-life" is clearly a topic
3. ✅ Scalable: root stays clean as topics grow
4. ✅ Follows best practices: logical grouping of related files
5. ✅ Better URLs: `/topics/shopping/phrases.html` is descriptive

## Detailed File Changes

### Files to Create
```
topics/                              # New directory
├── home-life/                      # Renamed from home/
├── shopping/                       # Moved from root
├── restaurant/                     # Moved from root
└── travel/                         # Moved from root
```

### Files to Move
**All topic HTML files** (25 files total):
- `home/*.html` → `topics/home-life/*.html` (10 files)
- `shopping/*.html` → `topics/shopping/*.html` (7 files)
- `restaurant/*.html` → `topics/restaurant/*.html` (1 file)
- `travel/*.html` → `topics/travel/*.html` (7 files)

### Path Changes in HTML Files

**1. CSS/JS Paths** (all topic pages):
```html
<!-- BEFORE -->
<link rel="stylesheet" href="../css/shared.css">
<script src="../js/shared.js"></script>

<!-- AFTER -->
<link rel="stylesheet" href="../../css/shared.css">
<script src="../../js/shared.js"></script>
```

**2. Navigation Links** (all topic pages):
```html
<!-- BEFORE -->
<button onclick="window.location='../home/phrases.html'">Home</button>
<button onclick="window.location='../shopping/phrases.html'">Shopping</button>

<!-- AFTER -->
<button onclick="window.location='../home-life/phrases.html'">Home Life</button>
<button onclick="window.location='../shopping/phrases.html'">Shopping</button>
```

**3. Home Icon** (all topic pages):
```html
<!-- BEFORE -->
<a href="../index.html" class="home-icon">🏠</a>

<!-- AFTER -->
<a href="../../index.html" class="home-icon">🏠</a>
```

**4. Section Navigation** (within same topic):
```html
<!-- BEFORE (in home/dialogue.html) -->
<button onclick="window.location='phrases.html'">Phrases</button>

<!-- AFTER (in topics/home-life/dialogue.html) -->
<button onclick="window.location='phrases.html'">Phrases</button>
<!-- No change - relative links within same folder -->
```

**5. Landing Page Links** (index.html):
```html
<!-- BEFORE -->
<a href="home/phrases.html">Home</a>
<a href="shopping/phrases.html">Shopping</a>

<!-- AFTER -->
<a href="topics/home-life/phrases.html">Home Life</a>
<a href="topics/shopping/phrases.html">Shopping</a>
```

## Risk Assessment

### Medium Risks
1. **Broken links**: Many links to update (mitigated by systematic approach)
2. **CSS/JS path errors**: One level deeper (mitigated by prototype testing)
3. **Missed files**: Easy to forget a file (mitigated by checklist)

### Low Risks
1. **Content corruption**: Just moving files, not editing content
2. **Lost work**: Can archive before starting
3. **Rollback**: Can revert if needed (pre-migration backup)

### Mitigation Strategies
1. **Prototype first**: Test approach on one topic
2. **Systematic updates**: Use checklist, don't skip files
3. **Test thoroughly**: Click every link manually
4. **Archive before**: Create safety net
5. **Work in temp/**: Test migration before applying to main files

## Automation Opportunities

### Find/Replace Patterns

**Pattern 1: CSS/JS paths in topic files**
```
Find:    href="../css/shared.css"
Replace: href="../../css/shared.css"

Find:    src="../js/shared.js"

```

**Pattern 2: Navigation to home topic**
```
Find:    ../home/
Replace: ../home-life/
```

**Pattern 3: Landing page topic links**
```
Find:    href="home/
Replace: href="topics/home-life/

Find:    href="shopping/
Replace: href="topics/shopping/

Find:    href="restaurant/
Replace: href="topics/restaurant/

Find:    href="travel/
Replace: href="topics/travel/
```

**Tool**: Can use bash script or text editor find/replace across files
