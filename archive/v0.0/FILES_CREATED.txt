=============================================================================
                          HOW TO USE
=============================================================================

1. OPEN THE APP:
   → Double-click index.html
   → Or run: python3 -m http.server 8000
   → Visit: http://localhost:8000

2. EXTRACT CONTENT:
   → Run: python3 extract_content.py shopping story-all
   → Copy from extracted/ folder
   → Paste into shopping.html

3. ADD NEW SCENARIOS:
   → Copy shopping.html as template
   → Update content
   → Add to index.html
   → Update navigation in all files
