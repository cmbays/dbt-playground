# TDD-019: Workflow Hub v0.7 - Multi-Session Orchestration Command Center

## Overview

**Source PRD**: PRD-019-WORKFLOW-HUB-V07
**Author**: Architect (Team 2)
**Status**: Draft
**Created**: 2026-01-31
**Updated**: 2026-01-31

### Summary

The Workflow Hub v0.7 transforms from a single-session resume tool into a multi-session orchestration command center. This technical design implements per-session state tracking, real-time polling, GitHub issues integration, and workflow stage visualization to enable a single human operator to manage 2-6 parallel Claude Code sessions. The architecture uses a decentralized file-based state pattern with client-side aggregation, maintaining the single-file HTML playground philosophy while scaling to multi-team coordination.

### Design Goals

1. **Decentralized State**: Each session writes independently to avoid file conflicts
2. **Real-Time Visibility**: 10-second polling provides near-instant blocker awareness
3. **Zero Server Dependency**: Hub works purely client-side (browser + file system)
4. **Backward Compatible**: Existing WORKFLOW_STATE.md coexists with new SESSION_STATE files
5. **Scalable**: Support 2-6 concurrent sessions without performance degradation

### Data Flow

1. **Session → State File** (Write): Each Claude Code session writes to `temp/SESSION_STATE/{session-id}.md`
2. **State Files → Hub** (Read): Hub polls all session files every 10 seconds
3. **Script → Issues Cache** (Write): `fetch-github-issues.py` updates `temp/github-issues-cache.json`
4. **Issues Cache → Hub** (Read): Hub polls issues cache every 60 seconds
5. **Hub → Display** (Render): Hub aggregates data and updates UI

#### Populating Dynamic Fields

**How agents should update SESSION_STATE fields:**

**`stage_progress`** (string, optional):

- **Purpose**: Show sub-task progress within current stage
- **Format**: Free-form text, but prefer "{completed}/{total} {units}" pattern
- **Examples**:
  - BUILD stage with models: `"3/7 models complete"`
  - VERIFY stage with tests: `"45/50 tests passing"`
  - PLAN stage with decisions: `"2/5 decisions made"`
  - DEPLOY stage: `"Merging PR #81"`
- **When to update**: After each sub-task completion
- **Rules**:
  - Keep it concise (<50 chars)
  - Focus on countable progress when possible
  - Null/empty is acceptable if no sub-tasks

**`recent_activity`** (array of objects):

- **Purpose**: Show recent actions for this session (displayed in Hub timeline)
- **Format**: Array of `{timestamp, message}` objects
- **Max size**: Keep to last 5-10 entries (Hub will trim to AppState.settings.maxRecentActivity)
- **When to add**:
  - Stage transitions: `"Started BUILD phase"`
  - Significant completions: `"Completed stg_customers model"`
  - Blocked status changes: `"Blocked: waiting for schema decision"`
  - Unblocked: `"Unblocked: decision received, resuming work"`
  - Test results: `"All tests passing (171/171)"`
  - PR events: `"Created PR #82"`, `"PR #82 approved"`
- **Rules**:
  - Use past tense for completions: "Completed", "Created", "Merged"
  - Use present continuous for in-progress: "Building", "Testing", "Reviewing"
  - Keep messages <100 chars
  - Always include ISO 8601 timestamp

**Example update sequence**:

**Generation Script**: `scripts/fetch-github-issues.py`

```python
#!/usr/bin/env python3
# /// script
# requires-python = ">=3.11"
# dependencies = ["PyGithub"]
# ///

"""
Fetch GitHub issues with priority labels and cache as JSON.
Run manually or via cron: */5 * * * * cd /path && uv run scripts/fetch-github-issues.py
"""

import json
import re
from datetime import datetime
from pathlib import Path
from github import Github
import os

def parse_dependencies(body):
    """
    Parse issue dependencies from body text.
    Looks for patterns like:
    - "Depends on #123"
    - "Blocked by #456"
    - "Blocks #789"
    """
    dependencies = {
        "blockedBy": [],
        "blocks": []
    }

    # Pattern: "Depends on #N" or "Blocked by #N"
    blocked_by_pattern = r'(?:Depends on|Blocked by|blocked by|depends on)\s+#(\d+)'
    for match in re.finditer(blocked_by_pattern, body, re.IGNORECASE):
        issue_num = int(match.group(1))
        if issue_num not in dependencies["blockedBy"]:
            dependencies["blockedBy"].append(issue_num)

    # Pattern: "Blocks #N"
    blocks_pattern = r'(?:Blocks|blocks)\s+#(\d+)'
    for match in re.finditer(blocks_pattern, body, re.IGNORECASE):
        issue_num = int(match.group(1))
        if issue_num not in dependencies["blocks"]:
            dependencies["blocks"].append(issue_num)

    return dependencies

def fetch_issues():
    token = os.getenv("GITHUB_TOKEN")
    if not token:
        raise ValueError("GITHUB_TOKEN environment variable required")

    g = Github(token)
    repo = g.get_repo("cmbays/dbt-playground")

    # Fetch open issues with priority labels
    issues = []
    for issue in repo.get_issues(state="open"):
        labels = [label.name for label in issue.labels]
        priority = next((l for l in labels if l.startswith("P")), None)

        if priority:  # Only include prioritized issues
            # Parse dependencies from issue body (FR-7: Dependency Visualization)
            dependencies = parse_dependencies(issue.body or "")

            issues.append({
                "number": issue.number,
                "title": issue.title,
                "priority": priority,
                "labels": labels,
                "state": issue.state,
                "url": issue.html_url,
                "created_at": issue.created_at.isoformat(),
                "assigned_to": issue.assignee.login if issue.assignee else None,
                "milestone": issue.milestone.title if issue.milestone else None,
                "dependencies": dependencies
            })

    # Sort by priority (P0 > P1 > P2), then by creation date
    priority_order = {"P0": 0, "P1": 1, "P2": 2, "P3": 3}
    issues.sort(key=lambda x: (priority_order.get(x["priority"], 99), x["created_at"]))

    # Write cache file
    cache_file = Path("temp/github-issues-cache.json")
    cache_file.parent.mkdir(exist_ok=True)

    cache_data = {
        "last_updated": datetime.now().isoformat() + "Z",
        "issues": issues
    }

    with open(cache_file, "w") as f:
        json.dump(cache_data, f, indent=2)

    print(f"✓ Cached {len(issues)} issues to {cache_file}")

if __name__ == "__main__":
    fetch_issues()
```

### Key Functions

#### 1. Polling Engine

```javascript
class PollingEngine {
  constructor() {
    this.intervals = {
      main: null,
      issues: null,
      tokenBudget: null
    };
    this.active = true;
  }

  start() {
    // Main poll: SESSION_STATE files + AGENT_REPORTS (10s)
    this.intervals.main = setInterval(async () => {
      if (!this.active) return;
      await this.pollSessionState();
      await this.pollWorkflowState();
      await this.pollAgentReports();
      updateLastRefreshTimestamp();
    }, AppState.settings.pollInterval);

    // Issues poll: GitHub cache (60s)
    this.intervals.issues = setInterval(async () => {
      if (!this.active) return;
      await this.pollGitHubIssues();
    }, AppState.settings.issuesPollInterval);

    // Token budget poll: Optional auto-polling (default: disabled)
    // If enabled, polls every 5 minutes via /usage command
    if (AppState.settings.tokenBudgetAutoPoll) {
      this.intervals.tokenBudget = setInterval(async () => {
        if (!this.active) return;
        await this.pollTokenBudgets();
      }, AppState.settings.tokenBudgetPollInterval);
    }

    // Initial fetch
    this.pollSessionState();
    this.pollGitHubIssues();
    if (AppState.settings.tokenBudgetAutoPoll) {
      this.pollTokenBudgets();
```

```javascript
function parseSessionState(content) {
  // Extract YAML frontmatter
  const frontmatterRegex = /^---\s*\n([\s\S]*?)\n---\s*\n([\s\S]*)$/;
  const match = content.match(frontmatterRegex);

  if (!match) {
    throw new Error('Invalid SESSION_STATE format: missing frontmatter');
  }

  const yamlContent = match[1];
  const markdownContent = match[2];

  // Simple YAML parser (assumes flat structure, no nested objects in values)
  const parsed = {};
  const lines = yamlContent.split('\n');

  let currentKey = null;
  let currentArray = null;

  for (const line of lines) {
    const trimmed = line.trim();
    if (!trimmed || trimmed.startsWith('#')) continue;

    // Array item
    if (trimmed.startsWith('- ')) {
      if (currentArray) {
        // Check if object or scalar
        if (trimmed.includes(':')) {
          // Object in array (e.g., recent_activity)
          const objMatch = trimmed.match(/- (\w+): (.+)/);
          if (objMatch) {
            const lastObj = currentArray[currentArray.length - 1] || {};
            lastObj[objMatch[1]] = parseValue(objMatch[2]);
            if (currentArray[currentArray.length - 1]) {
              currentArray[currentArray.length - 1] = lastObj;
            } else {
              currentArray.push(lastObj);
            }
          }
        } else {
          // Scalar in array (e.g., issues_assigned)
          currentArray.push(parseValue(trimmed.substring(2)));
        }
      }
      continue;
    }

    // Key-value pair
    const kvMatch = trimmed.match(/^(\w+):\s*(.*)$/);
    if (kvMatch) {
      const key = kvMatch[1];
      const value = kvMatch[2];

      if (!value) {
        // Array start
        currentKey = key;
        currentArray = [];
        parsed[key] = currentArray;
      } else {
        // Scalar value
        parsed[key] = parseValue(value);
        currentKey = null;
        currentArray = null;
      }
    }
  }

  // Parse markdown sections
  const sections = parseMarkdownSections(markdownContent);

  return {
    ...parsed,
    currentFocus: sections['Current Focus'],
    decisionsPendingText: sections['Decisions Pending'],
    recentCompletions: sections['Recent Completions'],
    nextActions: sections['Next Actions']
  };
}

function parseValue(value) {
  // Handle null
  if (value === 'null' || value === '~') return null;

  // Handle booleans
  if (value === 'true') return true;
  if (value === 'false') return false;

  // Handle numbers
  if (/^-?\d+(\.\d+)?$/.test(value)) return parseFloat(value);

  // Handle quoted strings
  if ((value.startsWith('"') && value.endsWith('"')) ||
      (value.startsWith("'") && value.endsWith("'"))) {
    return value.slice(1, -1);
  }

  // Default: string
  return value;
}

function parseMarkdownSections(markdown) {
  const sections = {};
  const headingRegex = /^## (.+)$/gm;
  let match;
  let lastHeading = null;
  let lastIndex = 0;

  while ((match = headingRegex.exec(markdown)) !== null) {
    if (lastHeading) {
      sections[lastHeading] = markdown.substring(lastIndex, match.index).trim();
    }
    lastHeading = match[1];
    lastIndex = match.index + match[0].length;
  }

  if (lastHeading) {
    sections[lastHeading] = markdown.substring(lastIndex).trim();
  }

  return sections;
}
```

```javascript
function createSessionCard(session) {
  const card = document.createElement('div');
  card.className = 'session-card';

  // Determine if stale
  const now = new Date();
  const lastUpdate = new Date(session.lastUpdated);
  const minutesSinceUpdate = (now - lastUpdate) / 1000 / 60;
  const isStale = minutesSinceUpdate > AppState.settings.staleThresholdMinutes;

  // Context health color
  const contextPct = session.contextUsagePct || 0;
  let contextColor = 'green';
  if (contextPct >= 80) contextColor = 'red';
  else if (contextPct >= 60) contextColor = 'yellow';

  card.innerHTML = `
    <div class="session-header">
      <h3>${session.branch}</h3>
      <div class="context-indicator" style="color: var(--accent-${contextColor})">
        Context: [${createProgressBar(contextPct)}] ${contextPct}%
      </div>
    </div>

    <div class="session-info">
      <div class="info-row">
        <span class="label">Worktree:</span>
        <span class="value">${session.worktree || 'Main repo'}</span>
      </div>
      <div class="info-row">
        <span class="label">Stage:</span>
        <div class="workflow-stages">
          ${renderWorkflowStages(session.stage)}
        </div>
      </div>
      ${session.stageProgress ? `
        <div class="info-row">
          <span class="label">Progress:</span>
          <span class="value">${session.stageProgress}</span>
        </div>
      ` : ''}
      ${session.issuesAssigned && session.issuesAssigned.length > 0 ? `
        <div class="info-row">
          <span class="label">Issues:</span>
          <span class="value">${session.issuesAssigned.map(n => `#${n}`).join(', ')}</span>
        </div>
      ` : ''}
      <div class="info-row">
        <span class="label">Last updated:</span>
        <span class="value ${isStale ? 'stale' : ''}">
          ${formatTimeSince(lastUpdate)}
          ${isStale ? ' ⚠️' : ''}
        </span>
      </div>
    </div>

    <div class="session-actions">
      <button onclick="refreshContext('${session.sessionId}')">Refresh Context</button>
      <button onclick="viewSessionDetails('${session.sessionId}')">View Details</button>
    </div>
  `;

  return card;
}

function renderWorkflowStages(currentStage) {
  const stages = ['UNDERSTAND', 'PLAN', 'BUILD', 'VERIFY', 'DEPLOY'];
  const currentIndex = stages.indexOf(currentStage);

  return stages.map((stage, idx) => {
    let className = 'stage';
    if (idx < currentIndex) className += ' completed';
    if (idx === currentIndex) className += ' current';

    return `<span class="${className}">${stage}</span>`;
  }).join(' → ');
}

function createProgressBar(pct, total = 10) {
  const filled = Math.round((pct / 100) * total);
  const empty = total - filled;
  return '='.repeat(filled) + '-'.repeat(empty);
}

function formatTimeSince(date) {
  const now = new Date();
  const seconds = Math.floor((now - date) / 1000);

  if (seconds < 60) return `${seconds}s ago`;
  if (seconds < 3600) return `${Math.floor(seconds / 60)}m ago`;
  if (seconds < 86400) return `${Math.floor(seconds / 3600)}h ago`;
  return `${Math.floor(seconds / 86400)}d ago`;
}
```

```javascript
function renderBacklog() {
  const container = document.getElementById('backlog');
  const priorityGroups = {
    P0: AppState.issues.filter(i => i.priority === 'P0'),
    P1: AppState.issues.filter(i => i.priority === 'P1'),
    P2: AppState.issues.filter(i => i.priority === 'P2')
  };

  let html = `<h2>📋 BACKLOG (${AppState.issues.length} issues)</h2>`;

  for (const [priority, issues] of Object.entries(priorityGroups)) {
    if (issues.length === 0) continue;

    const priorityLabel = {
      P0: 'Critical',
      P1: 'High',
      P2: 'Medium'
    }[priority];

    html += `
      <div class="priority-group">
        <h3>${priority} - ${priorityLabel} (${issues.length})</h3>
        <ul class="issue-list">
    `;

    const displayLimit = 3;
    const displayIssues = issues.slice(0, displayLimit);

    for (const issue of displayIssues) {
      const assignedSession = findSessionForIssue(issue.number);
      html += `
        <li class="issue-item">
          <a href="${issue.url}" target="_blank">#${issue.number}</a>
          ${issue.title}
          ${issue.labels.filter(l => !l.startsWith('P')).map(l => `<span class="label">${l}</span>`).join(' ')}
          ${assignedSession ? ` → <span class="session-link">${assignedSession}</span>` : ''}
        </li>
      `;
    }

    if (issues.length > displayLimit) {
      html += `
        <li class="show-more">
          <button onclick="expandPriority('${priority}')">Show ${issues.length - displayLimit} more...</button>
        </li>
      `;
    }

    html += `
        </ul>
      </div>
    `;
  }

  container.innerHTML = html;
}

function findSessionForIssue(issueNumber) {
  for (const session of AppState.sessions) {
    if (session.issuesAssigned && session.issuesAssigned.includes(issueNumber)) {
      return session.branch;
    }
  }
  return null;
}
```
