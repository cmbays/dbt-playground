About Mermaid Diagrams

Mermaid is a JavaScript-based diagramming tool that uses text definitions to create diagrams. The code you write here renders into visual diagrams.

Supported Diagram Types

  • flowchart TD - Top-down flowchart
  • flowchart LR - Left-right flowchart
  • erDiagram - Entity relationship diagram
  • sequenceDiagram - Sequence diagram
  • classDiagram - Class diagram
  • stateDiagram-v2 - State diagram
  • gantt - Gantt chart

Flowchart Syntax

  • A[Rectangle] - Rectangle node
  • A(Rounded) - Rounded node
  • A{Diamond} - Diamond/decision
  • A([Stadium]) - Stadium shape
  • A --> B - Arrow connection
  • A --- B - Line connection
  • A -->|text| B - Arrow with label

Keyboard Shortcuts

  • Ctrl+Enter - Re-render diagram
  • Ctrl+S - Save diagram
  • Esc - Close modals
  • ? - Show this help

Zoom & Pan Controls

  • Scroll wheel - Zoom in/out on preview
  • Click and drag - Pan the diagram
  • +/- buttons - Zoom in/out
  • Fit button - Fit diagram to view
  • 1:1 button - Reset to 100% zoom

Tips

  • The preview updates automatically as you type
  • Use Templates for common diagram patterns
  • Save diagrams to your Library for later use
  • Export as Markdown to embed in documentation
  • Zoom and pan to navigate large diagrams
