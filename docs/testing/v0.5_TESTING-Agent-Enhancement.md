## Baseline Measurements (Pre-Optimization)

### B1: Token Usage Baseline

Capture current token usage for agent operations before any changes.

**Methodology**:

```bash
# Use Claude Code's /context command to capture baseline
/context  # Record token breakdown before optimization
```

**Metrics to Capture**:

| Metric | Measurement Method | Baseline Value |
|--------|-------------------|----------------|
| Agent file token count | Count tokens in each .md file | Record per agent |
| Custom agents total | Sum of all agent tokens | Record total |
| Agent selection overhead | Tokens to list/select agents | Record |
| Task invocation overhead | Tokens for Task tool call with allowed_tools | Record |

**Baseline Capture Script**:

```bash
# Run before any changes
echo "=== BASELINE CAPTURE $(date) ===" > temp/baseline-metrics.txt

# Count tokens per agent file (approximate: 1 token ≈ 4 chars)
for file in .claude/agents/*.md; do
  chars=$(wc -c < "$file")
  tokens=$((chars / 4))
  echo "$file: ~$tokens tokens" >> temp/baseline-metrics.txt
done

# Total agent tokens
total_chars=$(cat .claude/agents/*.md | wc -c)
total_tokens=$((total_chars / 4))
echo "Total agent tokens: ~$total_tokens" >> temp/baseline-metrics.txt

# Capture /context output
echo "Run /context and paste output below:" >> temp/baseline-metrics.txt
```

## Measurement Scripts

### Script 1: Token Counter

```bash
#!/bin/bash
# scripts/count-agent-tokens.sh
# Counts approximate tokens in agent files

echo "Agent Token Count Report - $(date)"
echo "================================"

total=0
for file in .claude/agents/*.md; do
  if [[ -f "$file" ]]; then
    chars=$(wc -c < "$file")
    tokens=$((chars / 4))  # Approximate: 1 token ≈ 4 chars
    total=$((total + tokens))
    printf "%-40s %6d tokens\n" "$(basename $file)" "$tokens"
  fi
done

echo "================================"
printf "%-40s %6d tokens\n" "TOTAL" "$total"
```

### Script 2: Frontmatter Validator

```bash
#!/bin/bash
# scripts/validate-frontmatter.sh
# Validates YAML frontmatter in agent files

echo "Frontmatter Validation Report - $(date)"
echo "========================================"

for file in .claude/agents/*.md; do
  if [[ -f "$file" ]] && [[ "$(basename $file)" != "AGENTS.md" ]] && [[ "$(basename $file)" != "README.md" ]] && [[ "$(basename $file)" != "DOC_MAINTENANCE.md" ]]; then
    # Check if file starts with ---
    first_line=$(head -1 "$file")
    if [[ "$first_line" == "---" ]]; then
      # Extract frontmatter and validate
      frontmatter=$(sed -n '1,/^---$/p' "$file" | tail -n +2 | head -n -1)

      # Check required fields
      has_name=$(echo "$frontmatter" | grep -c "^name:")
      has_desc=$(echo "$frontmatter" | grep -c "^description:")
      has_tools=$(echo "$frontmatter" | grep -c "^tools:")

      if [[ $has_name -gt 0 ]] && [[ $has_desc -gt 0 ]] && [[ $has_tools -gt 0 ]]; then
        echo "✅ $(basename $file) - Valid frontmatter"
      else
        echo "⚠️  $(basename $file) - Missing required fields"
      fi
    else
      echo "❌ $(basename $file) - No frontmatter found"
    fi
  fi
done
```
