## 📝 Documentation Philosophy

These are **living documents** - they're always kept current with the project state.

**Version-specific documentation** (plans, notes, testing results) is stored in `temp/` during development and archived in `archive/` after deployment.

**Historical documentation** is kept in `archive/v0.0/` for reference but is no longer actively maintained.
