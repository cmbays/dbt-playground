# Research Reports

This directory contains repository research reports generated by the Sage persona using the `/repo-research` skill.

## Purpose

Research reports capture learnings from external repositories to inform:
- Feature development (via PM handoff)
- Architecture decisions (via Architect handoff)
- Pattern adoption and best practices

## Naming Convention

```
REPO-RESEARCH-[repo-name]-[YYYY-MM-DD].md
```

Examples:
- `REPO-RESEARCH-flashcard-app-2026-01-25.md`
- `REPO-RESEARCH-ui-component-lib-2026-01-25.md`

## Report Template

All reports follow the template at `.claude/templates/repo-research-report-template.md`

## Workflow

```
/repo-research <url>  →  sage: generates report  →  pm:/arch: review
```
