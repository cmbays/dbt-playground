# 1:1 Check-in Command

Weekly 1:1 ritual between human lead and Supervisor for continuous improvement.

## Usage

```
/1-1              # Start or continue 1:1 check-in
/1-1 notes        # Show recent 1:1 notes
/1-1 history      # Show all 1:1 history
```

## What Happens

When you invoke `/1-1`, Supervisor will:

1. **Check cadence** - Alert if >7 days since last 1:1
2. **Load context** - Read `temp/1-1-NOTES.md` for continuity
3. **Structure conversation** around:
   - Team health assessment
   - What's working / what's not
   - Agent-level insights (synthesized)
   - Culture and process improvements
   - Action items
4. **Record notes** - Append timestamped entry to 1:1 notes file

## Cadence

- **Target**: Weekly (every 7 days)
- **Alert**: If >7 days since last 1:1, Supervisor will prompt scheduling
- **Flexibility**: Can skip if acknowledged, but requires explicit opt-out

## 1:1 Agenda Template

```markdown
### Since Last 1:1
- Releases shipped
- Major features
- Blockers resolved

### Team Health
- Overall rating (🟢/🟡/🔴)
- Velocity trends
- Morale signals

### Agent-Level Insights
- Friction points observed
- Agents needing attention
- Process improvements needed

### Discussion Topics
- Human's topics
- Supervisor's topics

### Action Items
- Human commitments
- Supervisor/team commitments

### Decisions Made
- Recorded for future reference
```

## Context Management

### Storage

- **Active notes**: `temp/1-1-NOTES.md`
- **Archive**: `temp/archive/1-1-NOTES-YYYY.md` (when >500 lines)

### Compaction

When 1:1 notes exceed 500 lines:

1. Extract key decisions and patterns
2. Archive detailed notes to yearly file
3. Keep summary + last 3 months in active file

## Why 1:1s with Supervisor Only?

Supervisor acts as your **Engineering Manager** for the agent team:

- Observes all agent interactions
- Synthesizes cross-agent patterns
- Surfaces friction and improvement opportunities
- Represents agent-level concerns in a single conversation

You don't need separate 1:1s with each agent because Supervisor aggregates their insights.
