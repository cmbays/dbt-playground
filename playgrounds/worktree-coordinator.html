Git Worktree Coordinator Help

What is this?

This tool helps you visualize and manage git worktrees - separate working directories that share the same repository. Perfect for parallel development with multiple Claude Code sessions.

How to Use

  • Copy the command shown and run it in your terminal
  • Paste the output into the text area
  • Click "Parse & Display" to see your worktrees
  • Or click "Load Sample Data" to see an example

Understanding the Display

  • Main Repository - Your primary working directory (highlighted with blue border)
  • Worktrees - Additional working directories on different branches
  • Status badges - Shows if working directory is clean or has changes

Keyboard Shortcuts

  • R - Refresh / re-parse data
  • ? - Show this help
  • Esc - Close modals

Common Worktree Commands

  • git worktree add ../repo--branch -b branch-name - Create new worktree
  • git worktree remove ../repo--branch - Remove worktree
  • git worktree prune - Clean up stale worktree entries

Tips

  • Use sibling directories: ../dbt-playground--feature-name
  • Create draft PR immediately when starting a worktree
  • Push commits so other worktrees can fetch changes
  • Remove worktree after merging PR
