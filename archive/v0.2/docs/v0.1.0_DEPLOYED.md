## Versioning Strategy Applied

### Git (Primary)
- Content versions tracked by git
- Use tags for milestones (v0.1.0, v0.2.0, etc.)
- View old versions: `git checkout v0.1.0`
- Compare versions: `git diff v0.1.0 v0.2.0`

### Archive Folder (Supplementary)
- Documentation snapshots
- Build notes and migration docs
- Test results
- **Not for content** (git handles that)

### What Goes Where
| Type | Git | Archive | Notes |
|------|-----|---------|-------|
| HTML/CSS/JS | ✅ | ❌ | Git is source of truth |
| Living Docs | ✅ | ✅ snapshot | Archive preserves "how it was" |
| Build Notes | ❌ | ✅ | Migration plans, test results |
| Temp Files | ❌ | ❌ (clean) | Only during active development |
