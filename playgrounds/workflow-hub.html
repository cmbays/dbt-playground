Workflow Hub v0.7.1 Help

What is this?

The Workflow Hub is your central command center for managing multiple Claude Code sessions. It answers: "Where are my teams?" "Who is blocked?" "How healthy is the system?"

Key Features (v0.7.1)

  • Quick Resume - Copy context for continuing work in new sessions
  • Session Details - Click "View Details" on blocked sessions for full context
  • Handoff Preparation - Click "Handoff" to prepare a session for team transition
  • Worktree Legend - Color-coded with parent branch visibility
  • Blocked Detection - Blocked sessions appear at the top
  • Workflow Stages - UNDERSTAND/PLAN/BUILD/VERIFY/DEPLOY visualization
  • GitHub Backlog - Issues grouped by priority (P0/P1/P2)

How It Works

  • Run uv run scripts/playground-server.py
  • Sessions write to temp/SESSION_STATE/*.md
  • Hub polls server every 10s for session updates
  • GitHub issues poll every 60s

Session State Format

Agents write YAML frontmatter files with: session_id, branch, stage, blocked, context_usage, etc.

Keyboard Shortcuts

  • R - Refresh now
  • P - Pause/resume polling
  • D - Dashboard view
  • K - Kanban view
  • S - Sync issues (Kanban)
  • ? - Show this help
  • Esc - Close modals

Kanban Board

  • Drag cards between columns to change status
  • Click card to see details and actions
  • Issues auto-sync from GitHub backlog

Token Budget Thresholds

  • Green - Under 60% (healthy)
  • Yellow - 60-80% (monitor)
  • Red - Over 80% (needs cleanup)

Related Tools

  • Worktree Coordinator - Full worktree management
  • Mermaid Designer - Create architecture diagrams
